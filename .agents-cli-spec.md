# Agent Spec

## Overview
A simple demonstration agent built with ADK using Gemini 3.8 Flash model, capable of answering general inquiries and using tools (weather and current time lookup).

## Language
`python`

## Example Use Cases
- User asks for a greeting or general knowledge -> Agent answers directly.
- User asks: "What's the weather in San Francisco?" -> Agent invokes `get_weather` tool and replies with the weather info.
- User asks: "What time is it in SF?" -> Agent invokes `get_current_time` tool and replies with the current time.

## Tools Required
- `get_weather`: Simulated weather lookup for locations.
- `get_current_time`: ZoneInfo-based current time lookup for queried cities.

## Model
`gemini-3.8-flash` via Vertex AI (`global` location).

## Constraints & Safety Rules
- Provide accurate and helpful information.
- Gracefully handle unknown timezones.

## Success Criteria
- Successfully scaffolded with `agents-cli`.
- Configured to use `gemini-3.8-flash`.
- Executes queries locally via `agents-cli run`.
